# 团队工作台

会话工作持有补充需求、隔离成果和文件应用回执。工作室持有模板、提案和阶段验收。蜂群管理成员和手动任务。Hive 看板记录协作会话的提交，跨机协作群管理聊天、连接和设备。旧入口按来源组织，用户需要逐处查询，模板阶段还可能与蜂群任务重复计数。

工作台按下一步组织。先填写目标，再选择单项委托、项目分工、跨设备分工或阶段模板。从待处理、推进中和历史三个视图直达原来的审批、问题、成果和执行记录。协作视图提供看板、跨机群和蜂群管理。交付继续遵循对应任务的审批、验收和文件应用规则。

工作台以现有记录为准。一次 Colony 快照提供根任务、模板运行、组建提案和手动任务。已归属其他记录的阶段和子任务折叠到父项。各项保留原 ID，创建、验收和应用仍通过对应业务接口。跨设备连接与会话 Hive 授权规则继续有效。

验收覆盖阶段去重、旧记录、权限边界、待确认与已交付区分、精确跳转、失败重试及会话和模板原有路径。
