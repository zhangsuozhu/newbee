# 蜂群团队模板 · 使用手册

> 适用版本：main `afdac16` 起（PR #224）。本手册面向日常使用，设计细节见 [colony-team-templates.md](colony-team-templates.md)。

## 0. 这是什么

让蜂群拥有**可复用的团队**：你描述要做什么 → 一个 main 角色（团队主理人）提出组建计划 → **你审批** → 系统自动建好角色、沟通机制和运营流程，沉淀为**模板** → 以后任何项目都能**引用这个模板**直接开工 → 团队按阶段闭环推进，**你负责验收**，不满意就打回重做，满意就继续迭代。

内置「产研团队」：产品经理 → UI交互设计师 → 架构师 → 研发工程师 → 测试工程师。

三个核心概念：
- **模板**：角色分工 + 阶段流水线 + 验收闸门 + 打回回退 + 轮次预算。**全局资产**，所有蜂群都能用。
- **提案**：main 角色产出的组建草案，等你审批。归属某个蜂群。
- **项目（运行）**：引用模板开的一个具体项目，有自己的蜂群、成员和推进记录。

## 1. 打开团队工作室（推荐：就在主界面）

**不用离开你熟悉的对话界面。** 团队功能已内嵌进默认主界面：

1. 打开 newbee 主界面：`https://<你的主机>:5151/`（本机 `https://127.0.0.1:5151/`，局域网 `https://192.168.0.8:5151/`）。首次需登录。
2. 看顶栏右侧的 **六边形 🐝 按钮**（「团队工作室」）。有项目等你验收/确认时，按钮上会出现**金色数字徽标**。
3. 点它，右侧滑出「团队工作室」面板，三个页签：
   - **项目**：进行中的团队项目。需要你处理的（待验收/待确认/受阻）会高亮排在最前。
   - **模板**：可复用的团队模板。点「用此模板开项目」。
   - **组建**：让 main 为你定制新团队，审批草案。

面板里所有操作（验收/打回/迭代/开项目/审批）都**内联完成**，不弹原生对话框，不跳页。按 Esc 或点 ✕ 关闭。

> 权限：**审批、开项目、验收、打回、迭代**需要管理权限。普通成员只能查看。
>
> 旧入口仍可用：`/colony.html` 蜂群工作台里也有「🧩 团队」按钮，功能相同。主界面面板是首选。

## 2. 最快上手：用内置产研团队开一个项目

**第一次用，推荐这条路（不用等 main 规划）：**

1. 团队面板 → 选 **「＋ 安装内置『产研团队』模板」** → 提示已安装。
2. 再次打开团队面板 → 选 **「模板 · 产研团队（5角色/5阶段）→ 开项目」**。
3. 弹出模板详情（只读，可看角色职责和阶段流水线），在下方填：
   - **项目目标**（必填）：写清楚要做什么。例：`做一个纯前端记账小程序：收支记录、分类管理、月度报表，数据存 localStorage，纯 HTML/CSS/JS 无依赖。`
   - **项目名称**（可选）。
4. 点 **「启动项目」**。

系统立即：
- 新建一个**项目蜂群**（名字=项目名）；
- 按模板建好 **5 个 AI 角色**（产品经理/UI交互设计师/架构师/研发工程师/测试工程师）；
- 自动派发**第一阶段**（产品调研设计）给产品经理。

随后项目出现在「团队工作室 → 项目」页（顶栏🐝按钮的徽标会提示需要你处理）。点「去处理」展开详情，随时验收/打回。

> 目标写得越具体（功能点、技术约束、交付物位置），团队产出越靠谱。

## 3. 让 main 从零组建一支自定义团队

想要内置之外的团队结构（比如内容团队、运营团队）：

1. 团队面板 → **「＋ 让 main 组建新团队」**。
2. 填 **「这个团队要做什么」**。例：`一支短视频内容团队：选题策划、脚本撰写、拍摄清单、剪辑规范、发布复盘，循环迭代。`
3. 点 **「发起提案」**。系统创建「团队主理人」(main) 角色并开始规划（只读，不改代码）。
4. 等草案就绪（面板里提案状态从「main 规划中」变为「草案待审批」；刷新面板查看）。
5. 点该提案 → 查看草案（角色 + 阶段流水线 + 闸门 + 回退目标 + 轮次上限）。
6. 点 **「批准并建模板」**，在确认框选：
   - **批准入库**：模板成为全局资产，以后可引用开项目。
   - **驳回提案**：不要这个方案（填理由）。
   - **让 main 重新规划**：草案不满意，带意见让它重做（最多 5 次）。

> 审批是**人的专属动作**，AI 不能替你批准。批准后模板入库，提案规划任务自动收尾。

## 4. 项目推进中：验收 / 打回 / 迭代

团队按阶段串行推进。每个阶段产出一份成果（文档/代码/报告），**已验收的成果会自动交给下一阶段作为输入**（这是团队的沟通机制）。

### 4.1 阶段闸门
- **需验收（review）**：阶段成果提交后停下，**等你通过或打回**。
- **自动推进（auto）**：阶段完成即自动验收并进入下一阶段（内置模板里「研发实现」是 auto）。

### 4.2 验收一个阶段
1. 打开团队工作室（顶栏🐝按钮）→ **项目**页，找到高亮的待验收项目，点 **「去处理」**。
2. 展开详情：阶段流水线（✓已完成 / 高亮当前 / 待开始）、当前任务、**阶段成果全文**。
3. 点 **「✓ 验收通过」** 或 **「↩ 打回重做」**，内联填意见（打回**必填理由**）→ 确认。
   - **通过**：流水线进入下一阶段。
   - **打回**：回到该阶段设定的 `rework_to` 环节重做，轮次+1，你的打回理由会作为「必须正面回应的反馈」交给重做的角色。
4. 想看角色具体怎么干的：点 **「查看执行会话 →」** 跳到它的真实会话。

> 内置产研团队的回退规则：测试打回→研发；架构打回→UI设计；UI设计打回→UI设计；PRD打回→产品调研。

### 4.3 走完一轮之后
最后一个阶段验收通过 → 项目变为 **「已完成待确认」**。项目面板里你可以：
- **「满意，结束项目」**：项目关闭。
- **「继续迭代」**：填下一轮要改进什么（会交给产品经理），团队带着反馈回到第一阶段开始第 2 轮。

### 4.4 轮次预算用尽
打回次数达到模板的 `max_rounds` 上限 → 项目 **「已停下（轮次用尽）」**，不会无限循环。项目面板里可 **「提高轮次预算并继续」**（追加 1~5 轮，总预算≤10）。

## 5. 用模型工具操作（对话里直接说）

在任意 newbee 会话里，模型可以调用 `Newbee.Tools.Team`（工具 `tool.team`）：

| 想做什么 | 工具调用 |
| --- | --- |
| 看有哪些模板 | `Newbee.Tools.Team.templates()` |
| 安装内置产研模板 | `Newbee.Tools.Team.seed()` |
| 让 main 组建团队 | `Newbee.Tools.Team.propose("组建产研团队做记账产品")` |
| 看组建提案 | `Newbee.Tools.Team.proposals()` |
| 引用模板开项目 | `Newbee.Tools.Team.start(template_id, "项目目标")` |
| 看项目列表 | `Newbee.Tools.Team.runs()` |
| 看项目状态 | `Newbee.Tools.Team.status(run_id)` |

你也可以直接用自然语言让模型做，例如：
> 「用产研团队模板帮我开一个项目，做 XXX」
> 「看看现在有哪些团队模板」

**注意**：模型工具**只能提案/开项目/查状态，不能审批和验收**——审批、验收、打回、迭代必须你在 WebUI 里点（人的专属权限）。

## 6. 查看产出与证据

- 每个阶段的成果（Honey）都带**交付物位置、验证方法、未覆盖范围**，在项目蜂群的工作卡/成果卡里可看。
- 阶段交接、验收、打回都记录在蜂群 Trace（工作轨迹）里，可审计。
- 点项目蜂群里的 AI 角色，可进入它的真实执行会话，看完整工作过程。

## 7. 常见问题

**Q：点了启动项目，角色没动？**
A：阶段任务派发后由执行器异步启动会话，稍等几秒刷新。若长时间不动，看项目面板当前任务的「下一步」提示；可能是模型凭据未配置（在原会话模型设置里修）。

**Q：任务卡在「blocked / 执行回执丢失」？**
A：这是系统的保护机制（不自动重放未知操作）。在工作卡点「答复并继续」恢复，或让模型继续。系统高负载时偶发，恢复即可。

**Q：某个角色反复做无效操作（如反复开浏览器）？**
A：这是模型行为问题。系统的 watchdog 会自动裁决停止；你也可以中断它的会话、补充明确指令让它聚焦交付。必要时人补位完成该阶段成果，再让角色提交。

**Q：模板能改吗？**
A：当前模板版本固定为 v1，运行中的项目用的是启动时的模板快照。要不同结构，让 main 重新组建一个新模板。

**Q：能多个项目同时跑吗？**
A：能。每次「启动项目」都建独立的项目蜂群，互不干扰。

**Q：普通成员能验收吗？**
A：不能。验收/审批/打回/迭代需要蜂群管理权限。
