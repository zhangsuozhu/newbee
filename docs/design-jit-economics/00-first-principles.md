# 认知 JIT 的分级编译经济学 — 第一性原理分析 (R0)

## 1. 第一性原理推导

newbee 的本质约束只有一个：LLM 推理是昂贵的、慢的、不确定的计算；确定性代码是便宜的、快的、可验证的计算。
环境的每一次任务循环里，模型都会重复消耗推理 token 去解决结构上相同的问题。
把需要推理的智能编译成确定性产物，就是一次投资：

- 成本 C：adapter 的合成 token + 评价成本 + 激活风险
- 收益 B：每次使用节省的推理 token × 使用次数的期望
- 风险 σ：使用频率的不确定性、任务分布漂移、工具本身退化的概率

核心功能点 = 分级编译经济学 (Tiered Compilation Economics, TCE)：
一个在线的投资决策系统，决定哪些模式值得从 L1(prompt) 到 L2(rule) 到 L3(tool)
编译升级、何时降级（deopt），并用实测数据持续校准自己的预测。

## 2. 现状缺陷

- D1 收益点估计: benefit = count x avg_tokens，无衰减无不确定性无成本摊销
- D2 无成本项: 只算收益不比较编译成本，违背投资本质
- D3 deopt 粗糙: success_rate<0.5 且 n>=5，混淆工具退化与分布漂移
- D4 无校准闭环: 预测从不与实测对账
- D5 无机会成本: 全局无预算视角

## 3. 设计原则

P1 一切编译决策是不确定性下的决策 -> 必须携带置信度
P2 预测必须被实测打分 -> Brier 式评分回灌
P3 分布会漂移 -> 时间衰减默认；deopt 区分工具坏与世界变了
P4 预算稀缺 -> 按 LCB/C 排序
P5 知识不丢 -> deopt 是降级不是删除
